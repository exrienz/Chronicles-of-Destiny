## Project Structure

```
Book-[X]-[Title]/
├── 01-Planning/        # Plot and chapter outlines
├── 02-Chapters/        # Written chapters (5000+ words each)
├── 03-Reference/       # Character status, summaries, critiques
└── World Setting/      # World state AT END of this book
    ├── Characters/     # By role: Main, Supporting, Antagonists, Minor
    ├── Locations/      # Geography and places
    └── Items/          # Artifacts and weapons
```

## The World of Mythosia

A living fantasy realm facing an existential demon threat. Features:
- Three magic systems (Celestial, Elemental, Shadow/Void)
- Nine distinct races
- Complex political factions and alliances
- The Holy Dome protecting four kingdoms from demon invasion
